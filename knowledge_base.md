## 1. Что такое Zerocoder

- Онлайн-университет зерокодинга (первый в СНГ по этому направлению).
- Учит быстро входить в IT без классического программирования: зерокодинг / no-code,
  нейросети, AI-инжиниринг, автоматизация.
- Есть лицензия на образовательную деятельность, выдают сертификат.
- Форматы: онлайн-курсы, практикумы, открытые лекции, интенсивы, бесплатные вводные уроки.
- Поддержка, сообщество, обновления программ.
- Официальный сайт: https://zerocoder.ru/

## 2. Основные направления

### 2.1. Нейросети и AI (взрослые)
- Старт в нейросетях с нуля: базовые принципы, как работать с нейросетями для текстов,
  изображений, рутины.
- Нейросети для профессий: автоматизация, анализ данных, контент, поддержка.
- Нейросети для разработки и IT: генерация медиаконтента, анализ данных, AI-ассистенты, автономные системы.
- AI-инжиниринг: интеграция API (ChatGPT, Midjourney, Perplexity и аналоги), создание AI-ботов.
- Инструментальные программы: конкретные инструменты (например, практикум по GigaChat).
- Вайб-кодинг (например, OpenClaw): создание рабочих помощников без глубокого кода.
- Премиальные программы и подписка «НейроАбонемент»: доступ к набору программ направления.
- Пример программ: «Нейротин», «ИИ-вселенная», «Нейроускорение», «Большой практикум по GigaChat».

### 2.2. Зерокодинг / No-code разработка
- Веб-разработка без кода: многостраничные сайты и веб-сервисы на Webflow, Framer, Bubble.
- Мобильные приложения: кроссплатформенные приложения на FlutterFlow, Adalo, Glide.
  Интеграция оплат, публикация в App Store и Google Play.
- Базы данных и автоматизация: Airtable, Directual, Make (Integromat), n8n, Albato.
  Автоматизация CRM, рассылок, рутины.
- Подходит новичкам без опыта программирования. Цель — быстрый вход в IT, фриланс, свои продукты.

### 2.3. Классическое программирование
- Python с нуля + ChatGPT: база Python и использование нейросетей как помощника.
- Scratch для детей от ~7 лет: первый язык, от основ до олимпиад.

### 2.4. Для детей
- Scratch-программирование, Python + ChatGPT для школьников.
- Цель: ранний старт в IT, 2 востребованных навыка: код + ИИ.

### 2.5. Бесплатные форматы (для знакомства)
- Бесплатный урок, открытые лекции, онлайн-практикумы, семинары.
- Темы: запуск стартапа на ИИ без команды, ИИ-агенты, боты без кода, нутрициолог-бот за 3 дня и т.п.
- Хороший первый шаг, если человек сомневается.
