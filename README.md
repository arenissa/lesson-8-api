# ВК-бот «Алина» — консультант Zerocoder на GigaChat API

Бот слушает входящие сообщения сообщества ВКонтакте и отвечает с помощью GigaChat API.
Имя бота — **Алина**. Она консультирует только по программам онлайн-университета Zerocoder,
мягко возвращает вне-тематические вопросы к обучению и не выдумывает факты.

Реальные токены и ключи в репозитории отсутствуют — все секреты лежат только в локальном `.env`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `vk_bot.py` | Точка входа: LongPoll ВК → GigaChat → ответ в ВК |
| `gigachat_client.py` | Интеграция с GigaChat API по официальной документации (SDK `gigachat`, OAuth, `chat/completions`) |
| `config.py` | Чтение настроек из `.env`, без секретов в коде |
| `system_prompt.md` | Подробный системный промпт Алины |
| `knowledge_base.md` | База знаний о курсах Zerocoder (подставляется в запрос как контекст) |
| `.env.example` | Названия переменных без значений — скопировать в `.env` |
| `.gitignore` | Запрещает коммитить `.env` |
| `requirements.txt` | Зависимости Python |

## 1. Что добавить в `.env` (заполняется вручную)

Скопируй шаблон и заполни своими значениями:

```powershell
Copy-Item .env.example .env
```

| Переменная | Для чего | Где взять |
|---|---|---|
| `VK_GROUP_TOKEN` | Ключ доступа сообщества: читать и отправлять сообщения от имени сообщества | ВК → Управление сообществом → Работа с API → Ключи доступа → Создать (нужно право `messages`) |
| `VK_GROUP_ID` | Цифровой ID сообщества для LongPoll | Управление сообществом → Настройки, либо цифры из ссылки `vk.com/club123456` |
| `GIGACHAT_CREDENTIALS` | Ключ авторизации GigaChat (Basic, Base64). SDK сам меняет его на временный `access_token` (живёт 30 минут) | Личный кабинет Sber Developers / GigaChat API |
| `GIGACHAT_SCOPE` | Тип доступа: `GIGACHAT_API_PERS` (физлица), `GIGACHAT_API_B2B` / `GIGACHAT_API_CORP` (бизнес) | Тот же кабинет, где выдан ключ |
| `GIGACHAT_MODEL` | Модель: `GigaChat` (Lite, быстро), `GigaChat-2`, `GigaChat-2-Pro` (сложные инструкции), `GigaChat-2-Max` (макс. качество) | Выбор модели в документации GigaChat |
| `GIGACHAT_BASE_URL` | Базовый URL для новых подключений. Обычно менять не нужно | `https://api.giga.chat/v1` |
| `SALES_FORM_URL` | Ссылка на форму отдела продаж — бот предлагает её в подходящий момент | Любая актуальная форма/лендинг на `https://zerocoder.ru/` |

Дополнительно в ВК включи **возможность писать сообщения сообществу** и **LongPoll API**
(Управление → Сообщения → включить; Работа с API → LongPoll → включить + тип `message_new`).

## 2. Безопасность

- `.env` внесён в `.gitignore` и не попадает в Git/GitHub. Проверка: `git status` не должен показывать `.env`.
- `.env.example` содержит только названия, без значений — его коммитить можно.
- В коде (`vk_bot.py`, `config.py`, `gigachat_client.py`) секреты не захардкожены — только `os.getenv(...)`.
- Никому не пересылай содержимое `.env`, не вставляй ключи в чаты и скриншоты.

## 3. Запуск

```powershell
# 1. Python 3.8–3.13 (требование SDK GigaChat)
python --version

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Заполнение секретов (вручную в блокноте/редакторе)
Copy-Item .env.example .env

# 4. Старт бота
python vk_bot.py
```

Если всё верно, увидишь: `Бот Алина запущен для сообщества: ...`.
Напиши сообществу в личные сообщения — бот ответит.

## 4. Как работает связка

1. `VkLongPoll` ждёт событие `MESSAGE_NEW` (`to_me`).
2. `gigachat_client.AlinaGigaChat` собирает системный контекст:
   `system_prompt.md` + `knowledge_base.md` (с подставленной `SALES_FORM_URL`)
   плюс последние 6 реплик диалога — и вызывает `GigaChat.chat(Chat(...))`
   (endpoint `/v1/chat/completions`, авторизация `Bearer <токен>` — всё внутри SDK).
3. Ответ режется под лимит ВК (4096 символов) и отправляется через `vk.messages.send`.
4. История хранится в памяти процесса (`_dialogs`), после перезапуска очищается.

## 5. Обновление базы знаний

Открой `knowledge_base.md` и правь направления/программы по данным с https://zerocoder.ru/.
Цены и даты лучше не вписывать как факты — они быстро устаревают; пусть бот ведёт на менеджера.
Системный характер Алины правится в `system_prompt.md` — перезапуск подхватит изменения без смены кода.
